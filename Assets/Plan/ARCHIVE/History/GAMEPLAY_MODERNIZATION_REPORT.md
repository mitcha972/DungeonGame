## B/C. Implemented decisions and files

1. Assets/Scripts/MenuController.cs: resolve DungeonFloorTest instead of nonexistent DungeonFloorTemp; confirm Loading is enabled before committing the start request; load its resolved index. Existing public Play callback preserved.
2. Assets/Scripts/LoadingScript.cs: IsValidDestination rejects negative/out-of-range indices, Main and Loading; invalid direct entry logs an actionable error instead of silently loading Main or recursing. Slider behavior and async transition retained.
3. Assets/Scripts/GamePlay/Combat/CharacterCombat.cs: intersect previous/current phase interval with damage window, process the duration endpoint, and explicitly sample melee contacts during active/crossed windows. Existing one-projectile guard retained. Paused elapsed time does not advance. A slow-frame catch-up samples the current weapon pose; it does not reconstruct historical weapon positions or implement swept melee.
4. Assets/Scripts/GamePlay/AttackHitBox.cs: share existing overlap query through SampleDamage, callable by combat and FixedUpdate. Existing character/destructible deduplication remains. Reject inactive/paused/dead sampling. Additional active-window overlap queries are a correctness tradeoff; no performance gain claimed.
5. Assets/Scripts/Systems/LevelingSystemScripts/LevelSystem.cs: ignore nonpositive awards, accumulate in long, retain bounded int observable state during level events, discard surplus at cap. No legitimate negative-XP caller was identified. Negative penalties would now need a deliberately designed separate API.
6. Assets/Editor/GameplayModernizationValidation.cs (+ .meta): Tools > Validation > Gameplay Modernization; checks enabled destinations, XP boundaries/events, combat interval cases and 300 maze graphs over 2x2/5x5/16x16 sizes and 100 seeds each. Graph checks cover reachability, reciprocal/bounded passages, tree edge count and a unique farthest exit. Temporary object and Random state are restored; user scenes are not opened/saved. Results go to docs/GAMEPLAY_MODERNIZATION_VALIDATION.txt when this Editor runner actually executes.

Alternatives rejected: replacing controller with Rigidbody, FSM with behavior tree, generator with BSP/MST, static scene selection with a new manager, or progression with a new service. None demonstrated benefits sufficient to justify serialization/design risk. No obsolete implementations were removed because the retained systems need runtime integration evidence first.
