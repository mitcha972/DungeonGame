# Status effects

Implemented 2026-11-13. Temporary, session-only effects shared by players and enemies; no new attribute, input, save or enemy AI owner.

## Configuration and runtime

`Assets/StatusEffects/{Poison,Slow,Bleeding}.asset` are immutable shared `StatusEffectDefinition` configurations. Stable case-sensitive `effectId` determines uniqueness. Inspector fields include name, description, icon, duration, tick damage/interval and movement/outgoing/incoming multipliers. Poison: 15s, 2 damage/2s; Slow: 10s, movement x0.6; Bleeding: 12s, 1 damage/1s. Three small authored symbol sprites live in `Assets/StatusEffects/Icons/`.

`StatusEffectController` owns `ActiveStatusEffect` snapshots, timers and source attribution. Public API: `TryApplyEffect(definition, sourceTransform)`, `HasEffect`, `GetRemainingDuration`, `RemoveEffect`, `ClearAllEffects`, read-only `ActiveEffects`. Result distinguishes Applied, AlreadyActive, InvalidEffect and InvalidTarget. Duplicate IDs never reset duration, stack strength or consume another potion. C# EffectApplied/EffectRemoved/ActiveEffectsChanged events expose committed state. EffectRemoved covers both manual removal and expiration. Runtime state is never written into definitions.

Multipliers combine by multiplication, with each definition and final product clamped to 0..10; base stats/speeds stay intact. CharacterStats exposes derived MovementMultiplier/EffectiveDamage; CharacterCombat snapshots effective attack damage for normal melee/projectiles. Incoming multiplier precedes existing armor/minimum-one damage. Existing minimum-one combat policy remains, including a zero multiplier. Legacy explicit ability-damage overloads do not yet apply outgoing modifiers.

## Timing and lifecycle

Uses scaled `Time.deltaTime`: inventory/dialogue do not pause timers; Settings pause does. First tick occurs after one interval, subsequent ticks strictly before expiration. Poison therefore has seven ticks (14 raw damage), Bleeding eleven ticks (11 raw damage). A long frame catches up all scheduled ticks; there is no final tick at exact duration. Damage goes through CharacterStats/EnemyStats/PlayerStats.TakeDamage, preserving armor, normal health UI/death, enemy XP/loot and source attribution. Configured damage is pre-armor, not guaranteed final HP loss. DoT does not use melee blocking or hit-recovery presentation.

Death and disabling/destruction clear temporary state; disabled/dead/missing-health targets reject applications. Scene-owned effects do not persist across scene reloads. EnemyAi derives NavMeshAgent speed each Update; StarterAssets ThirdPersonController multiplies walk/sprint target speed without changing base values. PlayerHolder and Enemy_Main explicitly carry the controller, and CharacterStats requires it for newly added stats. Other already-authored player/enemy prefab variants may need the component added explicitly; RequireComponent does not retrofit old serialized instances.

## HUD and consumable

StatusEffectHUD lives under PlayerHolder's existing UICanvas, top left below health at (20,-100). Compact 40x48 icons with 46px spacing use gold TMP ceil-seconds countdowns. Icons hide immediately on removal. UIPointerEvents drives a small local TMP tooltip with name, description, remaining duration and configured modifiers; this also works in scenes with no generic Tooltip singleton. No new Canvas or input/modal owner. Null icons have a gold-square fallback. Enemy consumers can query the same controller/events; no permanent enemy HUD added.

Existing Consumable gains an optional statusEffect branch. Poison Potion is a separate asset derived from Health Potion with poison symbol icon and no particles. It validates exact source slot, reserves it before application callbacks, restores on rejection, notifies after success and requests existing Drink animation. Duplicate attempts retain the potion and show a two-second message on StatusEffectHUD, with Tooltip_Warning as a fallback for targets without that HUD. Healing branch remains intact. `Combat_Test` has an explicit StatusEffectTestSupply which grants three potions at Start; it is not a production bootstrap. Future attacks, spells, traps and items should call the shared TryApplyEffect API.
